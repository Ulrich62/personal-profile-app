# Personal Profile App

A lightweight personal profile web application and JSON API built with Node.js and Express.

## Endpoints

- `GET /` — Returns `"Welcome to Camper Bot's homepage!"`
- `GET /hobbies` — Returns `"I cycle, go boating, and play guitar."`
- `GET /skills` — Returns `"JavaScript, Node.js, and Express.js!"`
- `GET /api/profile` — Returns JSON containing user profile information (name, hobbies array, skills array).

## Getting Started

```bash
npm install
npm start
```

## Running Tests

```bash
npm test
```
